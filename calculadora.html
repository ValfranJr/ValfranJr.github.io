Calculadora de Preço de Venda

Preencha os campos. Os percentuais são informados em % (ex.: 10).

Fórmula: (CMV + EMB) ÷ (1 − (Custo Fixo% + Lucro%))

Entrada esperadaCMV + EMB
/ Custo Fixo% + Lucro%

Dica: se o valor ficar inválido, verifique se (Custo Fixo% + Lucro%) é menor que 100%.

FAQ — Perguntas Frequentes

O que é CMV?

CMV é o Custo de Mercadoria Vendida: custo direto de produção, incluindo insumos e mão de obra direta.

O que é o custo da embalagem?

Custo associado à embalagem utilizada para o produto antes da venda.

O que é o percentual do custo fixo?

Percentual dos custos fixos (aluguel, salários etc.) alocado no cálculo do preço.

O que é o percentual de lucro?

Margem desejada sobre o custo total.

Exemplo de cálculo

Ex.: (50 + 5) ÷ (1 − (0,10 + 0,20)) = 55 ÷ 0,7 = 78,57.
